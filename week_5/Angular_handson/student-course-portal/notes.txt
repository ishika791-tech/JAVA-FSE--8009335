angular.json - Project configuration file.

tsconfig.json - TypeScript compiler configuration.

tsconfig.app.json - TypeScript configuration for the Angular application.

package.json - Contains project dependencies and npm scripts.

src/main.ts - Entry point of the Angular application.

src/app/app.ts - Root component of the application.

src/app/app.config.ts - Application configuration (providers, routing, etc.).

src/index.html - Main HTML page where Angular loads.
